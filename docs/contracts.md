# Operation contracts

Contracts for two system operations of the Place Order flow, taken from the system sequence diagram in `diagrams/ssd-place-order.puml`.

---

## Contract CO1: addItem


| Operation        | `addItem(itemId, quantity)`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cross-references | UC5 Manage Cart.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Pre-conditions   | A Customer is identified and is the current Customer.<br>The Customer is viewing the Menu of a Restaurant.<br>`itemId` identifies a Menu item on that Restaurant's Menu.<br>`quantity` is between 1 and 20.<br>The Cart is empty, or its Cart lines belong to the same Restaurant as the Menu item.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Post-conditions  | If the Cart had no Cart line for that Menu item:<br>&nbsp;&nbsp;• a Cart line cl was created;<br>&nbsp;&nbsp;• cl was associated with the Cart;<br>&nbsp;&nbsp;• cl was associated with the Menu item;<br>&nbsp;&nbsp;• cl.quantity was set to `quantity`.<br>Otherwise:<br>&nbsp;&nbsp;• the quantity of the existing Cart line was changed to its previous value plus `quantity`, and no second Cart line was created.<br>In both cases:<br>&nbsp;&nbsp;• if the Cart had no Restaurant, the Cart was associated with the Restaurant that offers the Menu item;<br>&nbsp;&nbsp;• the line total of that Cart line was changed to its unit price multiplied by its quantity;<br>&nbsp;&nbsp;• the subtotal of the Cart was changed to the sum of the line totals of its Cart lines, and the total was changed to that subtotal plus the Restaurant's delivery fee. |

## Contract CO2: placeOrder


| Operation        | `placeOrder()`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cross-references | UC6 Place Order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Pre-conditions   | A Customer is identified and is the current Customer.<br>The Customer has a delivery Address.<br>The Cart holds at least one Cart line.<br>All Cart lines belong to one Restaurant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Post-conditions  | The Order:<br>&nbsp;&nbsp;• an Order o was created;<br>&nbsp;&nbsp;• o was associated with the Customer;<br>&nbsp;&nbsp;• o was associated with the Restaurant of the Cart;<br>&nbsp;&nbsp;• o.deliveryAddress was set to the Customer's Address.<br>The Order lines:<br>&nbsp;&nbsp;• for each Cart line, an Order line ol was created;<br>&nbsp;&nbsp;• each ol was associated with o;<br>&nbsp;&nbsp;• ol.itemName, ol.unitPrice and ol.quantity were set to the name and the price of the Menu item and the quantity of the Cart line as they are at this moment, so that a later change to the Menu does not change this Order;<br>&nbsp;&nbsp;• ol.lineTotal was set to ol.unitPrice multiplied by ol.quantity.<br>The number, the status and the amounts:<br>&nbsp;&nbsp;• o.orderNumber was set to a number greater than every order number already issued in this run;<br>&nbsp;&nbsp;• o.status was changed to PLACED;<br>&nbsp;&nbsp;• o.paymentMethod was set to cash on delivery, the only payment method in this iteration;<br>&nbsp;&nbsp;• o.subtotal was set to the sum of the line totals of its Order lines, o.deliveryFee was set to the Restaurant's delivery fee, and o.total was set to the subtotal plus the delivery fee.<br>The Cart:<br>&nbsp;&nbsp;• every Cart line was disassociated from the Cart, leaving it empty;<br>&nbsp;&nbsp;• the Cart was disassociated from its Restaurant. |
